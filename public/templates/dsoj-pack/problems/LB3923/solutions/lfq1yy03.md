# B3923 [GESP202312 二级] 小杨做题 題解

## 思路分析

本题考查数组的基本运用。 

这里给出朴素做法，其他方法请读者自行尝试。

在 $n$ 天里，每天做的题是前两天之和（前两天除外），当某天的做题量超过了 $m$，那么以后的日子将不会再做题。

因此，我们可以从 $1$ 循环到 $n$，从第三天开始的做题量 $a_i$ 会等于 $a_{i-1} + a_{i-2}$，将总做题量加上 $a_i$ 后，判断该日做题量是否大于 $m$，若大于直接退出循环（因为后面的日子都不需要做题）。

最后输出总做题量即可。

## 核心代码

从 $1$ 循环到 $n$，第三天开始计算当日做题量和累计做题量，随后判断是否超出 $m$ 即可：

```cpp
a[1] = aa, a[2] = b;
for (int i = 1; i <= n; i++) {
    if(i >= 3) a[i] = a[i - 1] + a[i - 2];
    num += a[i];
    if(a[i] >= m) break;
}
```

## 注意事项

- 记得给 $a_1$ 和 $a_2$ 赋值哦；
- `break` 不要写成 `continue`！
