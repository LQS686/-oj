# B4496 [GESP202603 一级] 数字替换 题解

对于这道题目，解题的思路就是数位分离：我们从数字的最后一位开始，一个一个地把它拆下来，检查一下是不是 $4$。如果是 $4$，我们就把它换成 $8$；如果不是，就保持原样。

程序利用 `while` 循环对输入的整数进行逐位提取。通过对 $10$ 取模的操作，我们可以获取当前数字的最低位；随后，针对该位数值进行逻辑判断，如果它是 4，则改为 8。处理完当前位后，为了将其还原到正确的位置，我们需要维护一个代表位权的变量 $w$，每次循环中 $w$ 乘上 $10$ 倍，将修正后的数字与之相乘并累加到结果变量中。最后，通过整除 $10$ 的操作剔除已处理的末位，直至原数字被完全拆解。

参考代码：

```cpp
int B = 0, w = 1;
while (A > 0) {
    int c = ________; // 获取最低位
    if (________) ________; // 改为 8
    B = ________; // 将修正后的数字与之相乘并累加到结果变量中
    ________; // 更新位权 w
    ________; // 继续拆解原数字
}
cout << B << endl;
```

如果觉得上述做法，对数学基础较弱，没有理解过进制的学生不太友好的话，这里给出另外一种做法：循环读入。

我们把这个正整数视作一个一个字符，这样就可以使用 do-while 循环，使用 scanf 语句读入每一个字符，直到读入的字符不是数字字符为止。如果字符是 `4`，那么就改成 `8` 之后输出。否则按照原样输出。

这样的做法更加简洁。

```cpp
char c;
do {
    ________; // 使用 scanf 输入字符 c
    if (________) // 如果字符是数字字符 4
        ________; // 输出什么呢？
    else
        ________; // 输出什么呢？
} while (________); // 怎么判断一个字符 c 是数字字符呢？
```

此外，也可以改成 while 循环输入这些字符：

```cpp
while (cin >> c) {
    // 内部逻辑同上
}
```

这并不是什么罕见语法，更不是某些机构所说的“一千个题里面做不到一个”的冷门偏门知识点。使用 `while (cin >> c)` 读入不定数量的内容是较为常用的，需要知道的语法知识点。此外，请注意：GESP 大纲只规定了二级可以考察循环嵌套，并不规定“数位分离”等循环应用不能在一级考察。
