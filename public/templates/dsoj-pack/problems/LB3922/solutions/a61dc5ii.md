# B3922 [GESP202312 一级] 小杨报数 題解

## 思路分析

本题考查循环结构和分支结构。

从 $1$ 循环到 $N$，每次循环判断 $i$ 是否为 $M$ 的倍数，使用 `%` 运算符，若**结果为** $0$，说明**能被整除**，**跳过该数字**，否则就输出 $i$。

## 核心代码

循环从 $1$ 到 $N$，若 $i \mod M = 0$，说明 $i$ 不符题意不能被输出，否则输出：

```cpp
for (int i = 1; i <= N; i++) {
    if(i % M != 0) cout << i << endl;
    else continue;
}
```

## 注意事项

- 输出需要换行，`endl` 可替换为 `'\n'`。
