# B4498 [GESP202603 二级] 画画 题解

这道题要求我们根据输入的正整数 $n$，输出一个 $n \times n$ 的字符正方形。规则很清晰：四个角是 `+`，第一行和最后一行的中间部分是 `-`，第一列和最后一列的中间部分是 `|`，其余内部全部填 `*`。

我们只需要用两层循环遍历每一个位置 $(i, j)$，然后根据它所处的行列来判断应该输出哪个字符。具体来说：如果当前位置处于四个角（即行和列都是边界），就输出 `+`；如果处于第一行或最后一行，就输出 `-`；如果处于第一列或最后一列，就输出 `|`；否则就输出 `*`。每输出完一行后换行即可。

```cpp
for(________) { // 用两层循环遍历每一个位置 (i, j)
    for(________) {
        bool r = ________; // 是否为第一行或最后一行
        bool c = ________; // 是否为第一列或最后一列
        if (________) cout << '+'; // 根据 r 和 c 进行判断
        else if (________) cout << '-';
        else if (________) cout << '|';
        else cout << '*';
    }
    cout << ________; // 一行结束了，输出什么？
}
```
