# B3955 [GESP202403 二级] 小杨的日字矩阵

---

本题考察循环嵌套。

本题使用双重循环输出这一个正方形矩阵。外层循环 $i$ 为行号（从 $1$ 开始），内层循环 $j$ 为列号（从 $1$ 开始），接着我们判断行列关系：

- 如果是第一列或者最后一列（`j == 1 || j == n`），那么输出的是 `|`；
- 如果是第一行，第 $\frac{N+1}{2}$ 行或者最后一行（`i == 1 || i == (N + 1) / 2 || i == n`），那么输出的是 `-`；
- 对于其他位置，输出的是 `x`；

根据这三种情况，在循环内部使用分支结构输出即可。注意，每一行输出完毕后需要输出换行，且最后一行输出结束后无需再输出换行。

参考代码：

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        if (____条件 1____)
            cout << '|';
        else if (____条件 2____)
            cout << '-';
        else //对于其他位置
            cout << 'x';
    }
    if (i != n)
        cout << endl;
}
```
