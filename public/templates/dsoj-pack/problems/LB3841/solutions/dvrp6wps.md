# B3841 [GESP202306 二级] 自幂数判断

## 思路分析

因为不同位数，是不同的幂之和，所以我们需要先判断正整数 $n$ 的位数。可以通过除以 $10$ 并取整循环直到商变为 $0$ 来计算。之后将这个数分解为各位数字。可以使用取模运算 `%`得到每一位的值，然后用整除 `/` 操作去除当前位。对于每一位数字，计算它们的 $N$ 次方（ $N$ 即为该数的位数），并将这些次方累加到一个变量中。最后比较累加和与原数是否相等。

## 核心代码

判断该正整数 $N$ 有多少位。

```
while (N)
{
	N /= 10;
   	++p; //记录有多少位
}
```

依次对每一位进幂运算，并求和记录在 $sum$ 中。

```
while(N)
{
	b = a % 10;	
   	sum += pow(b, p); //p为位数，逐位运算求和
   	a /= 10;
}
```
