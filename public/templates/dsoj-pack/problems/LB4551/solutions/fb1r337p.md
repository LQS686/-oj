# B4551 [GESP202606 一级] 去旅行

分别算出三种方案的总价格。第一种方案不用转车，价格就是第一个数 $a$。第二种方案要先坐高铁到 C 市，再从 C 市坐飞机到 B 市，所以价格是第二个数加第三个数 $b+c$。第三种方案也是先到 C 市，再从 C 市坐高铁到 B 市，所以价格是第二个数加第四个数 $b+d$。

算出三个价格以后，要找出其中最小的一个。可以先把第一种方案当作当前最便宜的价格，然后拿第二种方案和它比，如果第二种更便宜，就改成第二种。再拿第三种方案和当前答案比，如果第三种更便宜，就改成第三种。这样一个一个比过去，最后留下来的就是最便宜的价格。

最后输出这个最小价格即可。本题数字都不大，直接用 int 就够了。
